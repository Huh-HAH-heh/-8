# Макет главного окна

## Расположение элементов

| **Учебная база данных** | |
|:---|:---|
| Подключение: SQLite | Статус: готово |

| **Факультеты** | **Академические группы** |
|:---|:---|
| Поиск не требуется | Код специальности: [____________] [Найти] [Сбросить] |
| ID · Номер · Название · Декан | ID · Номер группы · Код специальности · Факультет |
| Таблица факультетов | Таблица групп |
| [Добавить факультет] | [Добавить] [Изменить] [Удалить] |

## Формы

| **Факультет** | **Группа** |
|:---|:---|
| Номер факультета: [________] | Номер группы: [________] |
| Название: [______________] | Код специальности: [______] |
| Декан: [_________________] | Факультет: [выбрать ▼] |
| [Сохранить] [Отмена] | [Сохранить] [Отмена] |

## Поведение

- Выбор факультета или группы выполняется нажатием на строку таблицы.
- При создании группы факультет выбирается из списка существующих.
- Поиск фильтрует группы по `specialty_code`.
- «Сбросить» показывает все группы.
- Удаление факультета каскадно удаляет связанные группы (`ON DELETE CASCADE`).
- В строке состояния показывается результат последней операции.
