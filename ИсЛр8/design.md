# Шаг 1. Проектирование экрана

## Схема главного окна

Интерфейс предназначен для работы с таблицами `faculties` и `groups_table`. Родительская таблица — факультеты, дочерняя — академические группы. Связь между ними задаётся полем `groups_table.faculty_id`.

| **Факультеты** | **Управление факультетами** |
|:---|:---|
| Таблица: `faculties` | **[Добавить факультет]** |
| Столбцы: ID, Номер факультета, Название, Декан | Создание записи в родительской таблице |

| **Академические группы** | **Управление группами и поиск** |
|:---|:---|
| Таблица: `groups_table` | **Ключевое слово:** поле ввода |
| Столбцы: ID, Номер группы, Код специальности, ID факультета | **[Найти] [Сбросить]** |
| Записи отображаются вместе с факультетом, к которому они привязаны | **[Добавить группу]** |
| | **[Редактировать группу]** |
| | **[Удалить группу]** |

## Действия пользователя

| Элемент управления | Действие | Данные |
|:---|:---|:---|
| Добавить факультет | Создать факультет | Номер факультета, название, ФИО декана |
| Добавить группу | Создать академическую группу и привязать её к выбранному факультету | Номер группы, код специальности, факультет |
| Редактировать группу | Изменить выбранную запись | Поля выбранной группы |
| Удалить группу | Удалить выбранную группу | ID выбранной группы |
| Найти | Выполнить поиск по коду специальности | Поле `specialty_code` |
| Сбросить | Очистить поисковый запрос и показать все группы | Все записи `groups_table` |

## Правила работы интерфейса

- Обе таблицы отображаются одновременно.
- При добавлении группы пользователь выбирает факультет из существующих записей; его ID сохраняется в `faculty_id`.
- Редактирование и удаление группы выполняются после выбора строки в таблице групп.
- Поиск выполняется по полю `specialty_code` — именно это поле использует функция `search_child_by_keyword()` в `src/crud.py`.
- Кнопка «Сбросить» возвращает полный список групп.
- Удаление факультета приводит к удалению связанных с ним групп согласно внешнему ключу `ON DELETE CASCADE`.
- Строка состояния отображает результат операции или состояние подключения к SQLite.
